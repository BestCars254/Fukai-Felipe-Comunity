# 無料レッスン ②「サイドレイズで、肩より僧帽筋が疲れてしまう。」

ダンベルサイドレイズの徹底解説を、無料レッスンとして使う。
流れ：広告 → `/lesson-raise`（名前＋メール）→ 同じページで動画 → 見終わった直後に UNIÃO の案内（`/join`）。

## 公開前に必要なこと

1. 動画を YouTube に**限定公開**でアップロードする。
2. `lesson-raise.html` の `VIDEO_ID` に YouTube の ID を入れる（今は空。空の間は「動画を準備中です。」と表示される）。
   ID を入れると、鍵のかかったサムネイルも自動でその動画のものになる。
3. 動画の長さが決まったら、ページと広告カバーに「◯分」を入れる。

## 動画の要点（文字起こしから）

- 真横ではなく、肩甲骨の角度に合わせて 30° 前に挙げる。真横は僧帽筋が働きやすい
- 足は腰幅、手はポケットの位置。胸椎を伸ばし、肩を下げたまま挙げる
- 手ではなく肘で挙げる。手首はまっすぐ、手のひらは真下、肘は軽く曲げる
- 体を少し前に倒すと、トップで負荷が乗る
- 収縮で負荷が最大になる種目。挙げきれる重量で 8〜15 回
- 反動なしで 15 回できたら次の重量へ
- 筋肥大を優先するならケーブルかマシン。ダンベルはその代わりとして使える
- 胸椎の伸展が保てない場合は、ベンチにお腹をつけて行う

## 1. この種目は何をする種目なのか
- メインターゲット
- どんな動作を使う種目か
- 王道フォームとの違い
- このバリエーションを選ぶ理由

## 2. まず完成形を見せる
- Felipe の正解フォームを最初に実演（解説なし、ノーカット）
- 横・前・後ろなど必要な角度
- 「今日はこのフォームを作ります」とゴールを明確化

## 3. セットアップ
動き出す前に何を決めるか。
- 足幅
- グリップ
- シート位置
- 身体の角度
- 関節の位置
- マシンとの位置関係

## 4. 動作を徹底分解（動画の中心）
| 段階 | 問い |
|---|---|
| START | スタートポジション |
| ECCENTRIC | どこまで伸ばすか |
| TURNAROUND | 切り返しで何をするか |
| CONCENTRIC | どう収縮させるか |
| FINISH | どこまで動かしたら 1 rep 終了か |

力学（作用線・固定・モーメントアーム・テンポ）は、この5段階の中で必要な場面だけ出す。

## 5. よくある間違い・代償動作
- よく起こるフォームエラー
- どの筋肉が代わりに働きやすいか
- なぜその代償が起きるか
- どう修正するか

## 6. 重量を上げた時に見るポイント
- 重くなるとどこからフォームが崩れるか
- ROM は維持できているか
- 狙った関節運動が変わっていないか
- どこまでなら重量を上げていいか

## 7. レップ・強度・負荷設定
- おすすめレップレンジと、その理由
- RIR
- 重量の選び方
- いつ重量を上げるか

## 8. プログラムのどこに入れるか
- 序盤・中盤・終盤
- どんな種目の前後がいいか
- 週何回くらい使えるか

## 9. 合わない場合の代替案
- 骨格的に合わない
- 痛みが出る
- 腰など別部位が先に疲れる
- そのマシンがジムにない
→ その場合に何へ変更するか。Felipe 自身の経験も入れる。
例：ベントオーバーローで腰が先に疲れる → チェストサポート → バックエクステンションを使ったバリエーション

## 10. Felipe なら実際どう使うか（締め）
- 自分なら何を意識するか
- 何セットやるか
- どのタイミングで使うか
- どんな時にこの種目を外すか
- オフ・減量期などで変えるか
- PRO として一番重視しているポイント

## 撮影メモ
- 2 の実演と 3〜6 の解説カットは同じセットで続けて撮る。解説は実演映像の上に声を乗せる
- 0・7〜10・宿題は、全種目まとめて最後に座って同じ服で撮る
- テロップは項目番号と名前、4 では START / ECCENTRIC / TURNAROUND / CONCENTRIC / FINISH の5語だけ。固定デザインで使い回す
- 言葉：「僕は」「僕の場合」。誰も否定しない。「〜は間違い」ではなく「〜だと負荷が逃げる」

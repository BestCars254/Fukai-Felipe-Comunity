# 11/23（月）21:00 Instagram LIVE｜UNIÃO 説明ライブ 台本

目的：UNIÃO で何をするかを、見た人が人に説明できるくらい分かること。売り込みではなく「中身の説明」。
長さ：40〜45分（説明 25分 ＋ 質問 15〜20分）
言葉：「僕は」「僕の場合」。誰も否定しない。

Felipe が覚えるのは、各ブロックの**太字の一文**だけ。あとはその一文を自分の言葉で広げる。

---

## 0. 冒頭（2分）
**「筋肉のデカさには、理由がある。今日はその理由を、僕がどうやって全部渡すかを話します。」**
- 来てくれてありがとう。11/27 に UNIÃO を開きます
- 今日話すこと：①なぜ作ったか ②中身 ③入るとどうなるか ④料金と特典 ⑤質問
- コメントで「どこから見てる」「何年やってる」を聞く（場を温める）

## 1. なぜ作ったか（4分）
**「僕も2年止まった。変えたのは努力の量じゃなくて、トレーニングの見方だった。」**
- 重量は伸びていた。本気でやっていた。でも背中だけ変わらなかった
- 変えたのは、種目・フォーム・重量・レップ・強度・プログラム・回復に、全部理由をつけたこと
- 感覚でデカくなった人を見たことがない。デカい人は、なぜその種目かを説明できる
- 日本語でそれを全部言語化している場所がなかった。だから作った

## 2. 中身（8分）
**「毎週1本、1種目を10項目で分解する。それが積み上がる。」**
- 種目の徹底解説：完成形 → セットアップ → START/ECCENTRIC/TURNAROUND/CONCENTRIC/FINISH → 間違いと代償筋 → 重量を上げたとき見る場所 → レップと強度 → どこに入れるか → 代替案 → 僕ならどう使うか。10〜15分
- オープン時点で10本（ベントオーバーロー、チンニング、プルオーバー、サイドレイズ…）。以降、毎週1本
- トレーニング原則とプログラム設計：7つの要素を体系で。自分でメニューを組めるようになる
- フォームチェック：メンバーの動画を僕が見て、どこを見て何を直すかを解説
- Q&A・メンバー限定 LIVE・勉強会：迷ったらその場で聞ける。迷わせない
- ここで画面共有できるなら、LP の「手に入るもの」を見せる

## 3. 入るとどうなるか（4分）
**「自分のフォームのどこで負荷が逃げているか、自分で分かるようになる。」**
- 種目を選ぶ理由を、自分の言葉で言える
- 重量・レップ・強度を、自分で決められる
- 停滞したとき、7つのどこが抜けているかを自分で探せる
- 迷ったら、僕に聞ける
- 「教科書を覚える」ではなく「自分のトレーニングを判断できる」状態

## 4. 誰向けか（2分）
**「1年以上やっているのに変わらない人。その人が一番変わる。」**
- 弱点を改善したい人、大会を目指す人、根拠がほしいトレーナー
- 初心者も入れる。ただ一番変化が大きいのは、鍛えているのに止まっている人

## 5. 料金と特典（5分）
**「パーソナル2ヶ月分の金額で、僕の全種目解説が1年間。」**
- 一般的なパーソナル：¥9,000 × 月4回 = ¥36,000、その日の種目だけ、理由は残らない
- UNIÃO：月 ¥6,980（1日約233円）。全種目、原則、フォームチェック、Q&A、LIVE。全部込み
- 3プラン：
  - FOUNDER 先着20名：¥66,000/年（月換算 ¥5,500・1日約181円）。一生この価格
  - EARLY 初期50名：¥6,980/月。継続中はこの価格
  - STANDARD：¥7,980/月
- 最初の70名の5大特典：①僕の1日サプリルーティン ②使用ギアリスト ③1日の食事とPFC ④増量期の落とし穴 ⑤限定オンライン勉強会 LIVE（Founder は少人数で事前質問を深く）
- 抽選：オンラインコーチング1名（Founder のみ）、フォームチェック3名、トレーニングアドバイス3名
- 注意：Founder は年額一括払い。事前登録は枠の確保を保証しない

## 6. 流れ（2分）
**「11/26 に事前登録者へ先行案内、11/27 オープン。Founder は先着20名。」**
- 今すぐやること：プロフィールのリンクから無料で事前登録（メールだけ）
- 11/26 の先行案内メールが Founder の入口。11/27 は一般オープン
- Circle というアプリの中で全部やる。スマホでも PC でも

## 7. 質問（15〜20分）
**「全部答えます。答えられないことは、答えられないと言います。」**
- 事前に集めた質問から3つ → コメントから
- 想定質問と答えの骨：
  - 初心者でも？ → 入れる。基礎から順に。一番変わるのは止まっている人
  - フォーム見てもらえる？ → 投稿された動画から定期的に取り上げる。全員毎回は約束できない
  - 退会は？ → 月額はいつでも。Founder は年額一括、条件は申込時に
  - Felipe 本人が答える？ → Q&A と LIVE は僕が答える。全部に即答はできないが、全部目を通す
  - 女性も？ → もちろん。7つの要素は同じ
  - 器具がない？ → 全種目に代替案を入れている

## 8. 締め（1分）
**「感覚でやる から、理由を知ってやる へ。11/27、待っています。」**
- プロフィールのリンクから事前登録
- 次のライブ・投稿の告知
- ありがとう

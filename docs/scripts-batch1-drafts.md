# UNIÃO 撮影用台本｜第4〜10弾（下書き案）

第1〜3弾（サイドレイズ／スミスショルダープレス／インクラインプレス）は Felipe 版が決定稿。
以下は同じ型での**下書き案**。数字（角度・レップ・RIR）と代替案は Felipe の判断で差し替える前提。
言葉は「僕は」「僕の場合」。誰も否定しない。「間違い」ではなく「負荷が逃げる」。

## 第4弾：ペックフライ（マシン）

**0. 結論（15秒）**
「フライで肩の前ばかり疲れる人は、腕で寄せています。胸で寄せる位置を作ります。」

**1. この種目は何をする種目なのか（約1分）**
- メインターゲット：大胸筋（中部〜下部。シート高で上部寄りにも振れる）
- どんな動作か：肩関節の水平内転。肘の角度を固定したまま、上腕を胸の繊維走行に沿って内側へ寄せる単関節種目
- 王道との違い：ハンドルを「手で前に持っていく」のではなく、肘の内側（上腕）で寄せる。ストレッチ位置で止まらず、負荷が抜けない範囲で動かす
- このバリエーションを選ぶ理由：マシンは軌道が固定され、ストレッチ位置でも張力が残る（ダンベルフライはボトムで負荷が抜けない代わりに肩への負担が大きい）。胸だけに張力を置きやすい

**2. 完成形（約30秒）**
- 3〜5レップ、正面・側面
- 「今日は、腕ではなく大胸筋の内側で寄せ切るフォームを作ります。」

**3. セットアップ（約2分）**
- シート高：ハンドルを持ったとき、肘の高さが乳頭〜大胸筋下部のラインに来る高さ。肩より高いと三角筋前部に逃げる
- 背中：肩甲骨を軽く下制・内転し、背もたれに胸椎上部をつける。胸を張りすぎて腰を反らせない
- グリップ：手首は真っ直ぐ。握り込まず、前腕の内側〜肘でパッド／ハンドルを押す意識
- 肘の角度：軽く曲げた角度（10〜20度）で固定。動作中に変えない
- 足：床をしっかり踏む。足で体幹を固定し、上体を動かさない

**4. 動作の徹底分解（約4分）**
- START：ハンドルを持ち、肩甲骨を下制。胸にわずかな張力が乗った位置から
- ECCENTRIC：肘の角度を保ったまま、上腕を開く。大胸筋がストレッチされ、肩の前に「引っかかり」が出る手前まで。それ以上開くと負荷は肩関節に移る
- TURNAROUND：ストレッチの底で一瞬止めない。張力が最大の位置で、胸で切り返す
- CONCENTRIC：肘の内側で弧を描いて寄せる。手ではなく上腕を動かす
- FINISH：ハンドルが触れる手前、大胸筋が最大収縮した位置。無理に手を交差させない
- 力学：モーメントアームが最大なのは腕が開いた位置。ここで肘を曲げて逃げると、その瞬間だけ楽になる＝胸の張力が消える。肘の角度固定がこの種目の全部

**5. よくある間違い・代償動作（約2分）**
- ①肘が動作中に曲がる → 原因：重量が重すぎる → 代償：上腕二頭筋と前腕 → 修正：重量を落として肘固定
- ②肩がすくむ・前に出る → 原因：シートが低い、または胸を張れていない → 代償：三角筋前部・僧帽筋上部 → 修正：シートを上げ、肩甲骨を下制してから動く
- ③上体を前に倒して寄せる → 原因：収縮位置で張力に負ける → 代償：体幹の反動 → 修正：背中を背もたれから離さない

**6. 重量を上げた時に見るポイント（約1.5分）**
- 肘の角度が変わっていないか
- 開く位置が浅くなっていないか（可動域が縮む＝重量オーバー）
- 肩が前に出ていないか
- 1つでも出たらその重量はまだ早い

**7. レップ・強度（約1分）**
- 10〜15レップ。単関節で関節への負担が少なく、張力時間を長く取れるレンジ
- RIR 0〜1
- 15レップを肘固定でコントロールできたら1段階上げる

**8. プログラムの位置（約1分）**
- プレス種目の後（中盤〜終盤）。または、肩に不安がある人はプレスの前に軽く入れて「胸で動く感覚」を作る
- 週1〜2回

**9. 代替案（約1分）**
- 肩の前に痛み → ケーブルクロスオーバー（肘の高さと角度を自由に調整できる）
- マシンがない → ダンベルフライ（ただしボトムで負荷が抜けるので、可動域を浅めに、ストレッチの底で止めない）
- 胸上部に振りたい → シートを下げてハンドルが胸上部の高さに来るように

**10. Felipe なら（約1分）**
- プレスの後に2セット、収縮で2秒止める
- 重視するのは「開いた位置で胸に張力が残っているか」。収縮より、ストレッチ位置の質
- スパイス案：最後の1セットは収縮で2秒止めて、戻りを3秒で

**宿題（15秒）**
「次の胸トレで、肘の角度を固定したまま寄せる1セットを横から撮って、フォーム記録に上げてください。」

## 第5弾：チンニング（懸垂）

**0. 結論（15秒）**
「懸垂で腕と肩が先に終わる人は、肩甲骨が動いていません。背中で引く順番を作ります。」

**1. この種目（約1分）**
- メインターゲット：広背筋、大円筋（補助：僧帽筋中下部、上腕二頭筋）
- どんな動作か：肩関節の内転・伸展と肩甲骨の下制・下方回旋。閉鎖性運動連鎖（身体の方が動く）
- 王道との違い：「顎をバーの上に出す」を目標にしない。肩甲骨を下げてから肘を骨盤に向けて引く。可動域は、背中で引ける範囲だけ
- 選ぶ理由：自重で背中全体に高い張力をかけられる。肩甲骨の動きを自分でコントロールする感覚が、他の全ての引く種目の基礎になる

**2. 完成形（約30秒）**
- 3〜5レップ、側面・後面
- 「今日は、肩甲骨を下げてから肘で引く、背中が主役の懸垂を作ります。」

**3. セットアップ（約2分）**
- グリップ幅：肩幅よりやや広め（上腕が体幹に対して斜め45〜60度で下りてくる幅）。広すぎると可動域が消え、狭すぎると二頭が主役になる
- 握り：順手。親指は上から（サムレス）でもよい。握り込まず「引っかける」
- スタート姿勢：ぶら下がった状態で肩をすくめない。肩甲骨を下制した「デッドハング一歩手前」から
- 体幹：腹圧で肋骨を締め、腰を反らせない。脚は軽く前方か、膝を曲げて固定
- 胸：軽く張る（胸椎伸展）。バーに胸を向ける

**4. 動作の徹底分解（約4分）**
- START：肩甲骨を下制し、広背筋に張力が入った位置
- CONCENTRIC：肘を骨盤の方向へ引く。「上がる」ではなく「肘を下げる」。胸をバーに近づける
- FINISH：肘が体側に来て、肩甲骨が下方回旋し切った位置。顎の高さは結果であって目標ではない
- ECCENTRIC：肘を伸ばしながら、肩甲骨を最後にゆっくり挙上させる。ここで広背筋が最大ストレッチ
- TURNAROUND：肩がすくみ切る手前で、肩甲骨を下制するところから次のレップ
- 力学：作用線は常に鉛直。肘を前に出す（体幹に対して90度に開く）とモーメントアームが肩関節に乗り、負荷が三角筋後部と二頭に逃げる。肘を斜め下へ

**5. よくある間違い・代償動作（約2分）**
- ①肩がすくんだまま引く → 原因：肩甲骨下制ができていない → 代償：僧帽筋上部・二頭 → 修正：デッドハングからの「肩甲骨だけ下げる」練習を先に
- ②反動（キッピング）→ 原因：筋力不足 → 代償：腸腰筋・腰 → 修正：補助バンド、またはラットプルダウンで同じ動きを先に
- ③肘が前に出る（上腕が体幹に対し90度）→ 代償：三角筋後部 → 修正：グリップ幅を少し狭く、肘を斜め下に

**6. 重量（加重）を上げた時に見るポイント（約1.5分）**
- 肩甲骨の下制が最初に消える。ここが崩れたら重量オーバー
- ボトムで肘が伸び切らず、可動域が浅くなっていないか
- 身体が前後に揺れていないか

**7. レップ・強度（約1分）**
- 6〜10レップ。できない人は補助バンドで同じレンジ
- RIR 1〜2（フォームが崩れる手前で止める。懸垂は崩れると一気に腕の種目になる）
- 10レップをストリクトでできたら加重1.25〜2.5kg

**8. プログラムの位置（約1分）**
- 背中セッションの1種目目（最もフレッシュな状態で、肩甲骨の動きを作る）
- 週1〜2回

**9. 代替案（約1分）**
- 1回もできない → ラットプルダウン（同じ肘の軌道）、補助付きチンニングマシン
- 肘・前腕が痛い → ニュートラルグリップ（パラレル）
- 肩の前が引っかかる → グリップを少し狭く、または逆手（チンアップ）で上腕を体幹に近づける

**10. Felipe なら（約1分）**
- 背中の日の1種目目、加重で2〜3セット
- 一番重視するのは「ボトムで肩甲骨を上げ切ってから、下げ切る」。ここをサボると背中は広がらない
- スパイス案：最後のセットは自重でネガティブ4秒

**宿題（15秒）**
「次の背中トレで、ぶら下がって肩甲骨だけ下げる動きを5回、その後に懸垂3回。横から撮ってフォーム記録へ。」

## 第6弾：チェストサポートロウ

**0. 結論（15秒）**
「ベントオーバーローで腰が先に疲れる人へ。腰を外して、背中だけで引く種目です。」

**1. この種目（約1分）**
- メインターゲット：広背筋・大円筋・僧帽筋中部（パッド角度とグリップで配分が変わる）
- どんな動作か：胸をパッドで支えた状態での肩関節伸展・肩甲骨内転。体幹の固定をマシンに任せる
- 王道との違い：「重さを引く」ではなく、「胸をパッドから離さずに、肘を後ろへ」。パッドを押し返す力で肩甲骨の動きを引き出す
- 選ぶ理由：腰と脊柱起立筋を使わない。ベントオーバーローで腰が先に終わる人（骨格的に上体を支えにくい人）が、背中に集中できる

**2. 完成形（約30秒）**
- 3〜5レップ、側面・後面
- 「今日は、胸をパッドに預けて、肩甲骨と肘だけで引くロウを作ります。」

**3. セットアップ（約2分）**
- パッド高：胸の中央（乳頭のやや上）がパッドの上端に当たる高さ。低すぎると肩がすくむ
- 足：床または足置きをしっかり踏む。踏む力で胸をパッドに押しつける
- グリップ：狙いで変える。ニュートラル・狭め＝広背筋、順手・広め＝僧帽筋中部・三角筋後部
- 肩甲骨：スタートで前方へ出す（プロトラクション）。ここが広背筋のストレッチ
- 首：顎を引き、首で引かない

**4. 動作の徹底分解（約4分）**
- START：腕を伸ばし、肩甲骨を前に出して背中をストレッチ。胸はパッドに密着
- CONCENTRIC：肩甲骨を寄せながら、肘を骨盤方向へ引く。胸はパッドから離さない
- FINISH：肘が体側を通過し、肩甲骨が寄り切った位置。手は結果
- ECCENTRIC：肘を伸ばしながら、最後に肩甲骨を前へ出す。ここまでが1レップ
- TURNAROUND：肩甲骨が出切った位置で、背中の張力が消える手前で切り返す
- 力学：胸がパッドから浮いた瞬間、脊柱起立筋が仕事を始める。この種目の価値はそこを消すこと。「パッドを押す」が固定（ブレーシング）の全部

**5. よくある間違い・代償動作（約2分）**
- ①胸がパッドから浮く → 原因：重すぎる → 代償：脊柱起立筋・腰 → 修正：重量を落とし、足で踏んで胸を押しつける
- ②肩がすくむ → 原因：パッドが低い、肘が外に開く → 代償：僧帽筋上部 → 修正：パッドを上げ、肘を体側に沿わせる
- ③手で引く → 原因：握り込み → 代償：前腕・二頭 → 修正：ストラップ、または「肘で引く」合図

**6. 重量を上げた時に見るポイント（約1.5分）**
- 胸がパッドから浮いていないか（最初に崩れる場所）
- ストレッチ位置で肩甲骨が前に出なくなっていないか（可動域が縮む）
- 肩がすくんでいないか

**7. レップ・強度（約1分）**
- 8〜12レップ
- RIR 0〜1（体幹が固定されているので限界まで追いやすい）
- 12レップをストリクトでできたら1段階

**8. プログラムの位置（約1分）**
- 背中セッションの2〜3種目目（懸垂やデッドリフトの後、腰が疲れた状態でも背中を追える）
- 週1〜2回

**9. 代替案（約1分）**
- マシンがない → インクラインベンチにうつ伏せのダンベルロウ（同じ原理）
- 肩の前が痛い → ニュートラルグリップで肘を体側に
- 腰を鍛えたい人は、この種目で背中を学んだ後に、バックエクステンションで腰を強くしてからベントオーバーローへ（第0弾の話につなぐ）

**10. Felipe なら（約1分）**
- 背中の日の2種目目、2〜3セット。重さより、ストレッチ位置での肩甲骨の動き
- 一番重視するのは「エキセントリックの最後に肩甲骨を前に出すこと」。ほとんどの人はここを省略する
- スパイス案：収縮で1秒止め、肩甲骨を寄せた状態で肘をさらに後ろへ

**宿題（15秒）**
「次の背中トレで、胸をパッドから離さずに引く1セットを横から撮って、フォーム記録へ。」

## 第7弾：ハイバースクワット

**0. 結論（15秒）**
「スクワットで腰と膝ばかり疲れる人は、深さではなく、上体の角度で負荷が逃げています。」

**1. この種目（約1分）**
- メインターゲット：大腿四頭筋（補助：大臀筋、内転筋）
- どんな動作か：バーを僧帽筋上部に乗せ、上体を立てたまま股関節・膝関節を同時に曲げる。ローバーより膝が前に出て、四頭筋のモーメントアームが長くなる
- 王道との違い：「深くしゃがむ」が目標ではなく、「上体の角度を変えずにしゃがめる深さ」が自分の可動域。足幅・つま先の向きを骨格に合わせる
- 選ぶ理由：クラシックフィジークで最も必要な四頭筋の張力。上体が立つため、腰への負担をローバーより小さくできる

**2. 完成形（約30秒）**
- 3〜5レップ、側面・正面
- 「今日は、上体の角度を保って、四頭筋に負荷を置き続けるスクワットを作ります。」

**3. セットアップ（約2分）**
- バー位置：僧帽筋上部の「棚」に乗せる。首に当てない。肩甲骨を寄せて棚を作る
- グリップ：肩に痛みが出ない範囲で狭め。手首を反らせない
- 足幅：肩幅前後。つま先は15〜30度外。しゃがんだとき膝がつま先と同じ方向を向く幅が「自分の幅」
- ラックアウト：2歩で位置を決める。歩きすぎない
- ブレーシング：息を吸って腹圧。肋骨を締め、骨盤をニュートラル。「胸を張る」で腰を反らせない
- 視線：やや前下。上を見ると腰が反る

**4. 動作の徹底分解（約4分）**
- START：腹圧をかけた直立。膝は軽く緩める
- ECCENTRIC：股関節と膝を同時に曲げる。膝はつま先方向へ前に出てよい。上体の角度は最初の10cmで決まり、それを底まで変えない。深さは「骨盤が後傾し始める手前（バットウィンク前）」まで
- TURNAROUND：底で止まらない。ただし跳ね返りも使わない。足裏の真ん中（ミッドフット）に重心を感じて切り返す
- CONCENTRIC：胸と股関節を同時に上げる。腰だけ先に上がる（お尻が先に浮く）とグッドモーニングになり、負荷は腰へ
- FINISH：直立。膝を伸ばし切ってロックして休まない。次のレップへ
- 力学：バーの作用線は鉛直。ミッドフットの真上にバーがある限り、バランスは保たれる。上体が前に倒れると、バーが前に移動し、股関節と腰のモーメントアームが増える。それが「腰で挙げるスクワット」

**5. よくある間違い・代償動作（約2分）**
- ①お尻が先に上がる（グッドモーニング化）→ 原因：四頭筋が負荷に負けて股関節に逃がす → 代償：脊柱起立筋・ハム → 修正：重量を落とし、「胸と腰を同時に」
- ②膝が内に入る（ニーイン）→ 原因：中臀筋の弱さ、足幅が広すぎる → 代償：膝の靭帯への剪断 → 修正：足幅を狭く、膝をつま先へ
- ③踵が浮く → 原因：足首の可動域不足 → 修正：ヒールの高いシューズ、またはプレートを踵に

**6. 重量を上げた時に見るポイント（約1.5分）**
- 上体の角度（最初に崩れる）
- 深さが浅くなっていないか
- 底で腰が丸まっていないか
- 上がるときにお尻が先に浮いていないか

**7. レップ・強度（約1分）**
- 6〜10レップ
- RIR 1〜2（スクワットは RIR 0 で崩れると危険。崩れる手前で止める）
- 10レップを上体角度を保ってできたら2.5〜5kg

**8. プログラムの位置（約1分）**
- 脚セッションの1種目目（最も出力が必要）。腰に不安がある人はレッグエクステンションやレッグプレスで四頭筋を先に温めてから2種目目
- 週1〜2回

**9. 代替案（約1分）**
- 腰が先に疲れる → ハックスクワット、レッグプレス（体幹の固定をマシンに任せる）
- 足首が硬い → ヒールエレベーテッド（踵を上げる）、またはセーフティバー
- 大腿骨が長く上体が倒れる → 足幅を少し広く、つま先をより外へ

**10. Felipe なら（約1分）**
- 脚の日の1〜2種目目、3セット。深さより上体角度
- 一番重視するのは「エキセントリックの最初の10cmで角度を決めること」。そこで決まった角度が底まで続く
- スパイス案：底で1秒止めるポーズスクワット。反動を消して四頭筋だけで上がる

**宿題（15秒）**
「次の脚トレで、上体の角度を変えずにしゃがめる深さまでの1セットを横から撮って、フォーム記録へ。」

## 第8弾：デッドリフト

**0. 結論（15秒）**
「デッドリフトで腰ばかり疲れる人は、床から引く前に負荷の位置が決まっていません。引く前が全部です。」

**1. この種目（約1分）**
- メインターゲット：脊柱起立筋、大臀筋、ハムストリング、広背筋（全身の後面）
- どんな動作か：床からバーを引き上げるヒップヒンジ主体の多関節種目。「引く」より「床を押す」
- 王道との違い：僕はパワーリフティング的な最大重量ではなく、背中とハムに張力を置く目的で使う。可動域とテンポを優先し、床で止めて1レップずつ組み直す
- 選ぶ理由：後面全体に最も高い負荷をかけられる。ただし腰が先に疲れる人は、第6弾（チェストサポート）と第9弾代替案から入る

**2. 完成形（約30秒）**
- 3〜5レップ、側面
- 「今日は、腰ではなく、股関節と脚で床を押すデッドリフトを作ります。」

**3. セットアップ（約2分）**
- バー位置：ミッドフットの真上（脛から2〜3cm）
- 足幅：腰幅。つま先はやや外
- グリップ：肩幅のすぐ外。オルタネイトかストラップ。握力で終わらないように
- 脛をバーに：膝を曲げて脛がバーに触れる位置。お尻は「膝より上、肩より下」
- 背中：胸を張り、腰はニュートラル。広背筋で「バーを身体に引きつける」（脇を締める）
- ブレーシング：息を吸い、腹圧。引く前に「バーのたわみを取る」（スラックを抜く）。この時点で負荷がハムと臀部に乗っていれば準備完了

**4. 動作の徹底分解（約4分）**
- START：スラックを抜き、全身に張力が入った状態。ここが最重要。この位置で腰に負荷があれば、引く前にやり直す
- CONCENTRIC（床〜膝）：床を押す。背中の角度を変えずに、膝を伸ばす。バーは脛に沿って垂直に
- CONCENTRIC（膝〜ロックアウト）：股関節を前に出す。腰を反らせてロックしない。臀部を締めて直立
- FINISH：直立、肩は後ろに引かない（肩すくめない）
- ECCENTRIC：股関節を後ろへ引きながらバーを腿に沿って下ろし、膝の下で膝を曲げる。逆再生
- TURNAROUND：床で完全に止める（デッドストップ）。バウンドさせない。毎レップ、セットアップし直す
- 力学：バーが身体から離れるほど、腰のモーメントアームが増える。「バーを脛・腿に沿わせる」は見た目の話ではなく、腰への負荷を最小にする唯一の方法

**5. よくある間違い・代償動作（約2分）**
- ①お尻が先に上がる → 原因：脚で押せていない → 代償：腰（グッドモーニング化）→ 修正：重量を落とし、「胸と腰を同時に上げる」。スタートでお尻の高さを少し下げる
- ②腰が丸まる → 原因：腹圧不足、ハムの硬さ → 代償：腰椎の靭帯・椎間板 → 修正：即重量を落とす。ブロックからの引き（可動域を短く）
- ③バーが身体から離れる → 原因：広背筋が緩んでいる → 代償：腰 → 修正：「脇を締める」合図

**6. 重量を上げた時に見るポイント（約1.5分）**
- スタートの背中の角度（引く前に腰が丸まる）
- お尻が先に上がる
- バーが脛から離れる
- ロックアウトで腰を反らせる
- 1つでも出たらその重量ではやらない。デッドリフトだけは「様子見」をしない

**7.レップ・強度（約1分）**
- 4〜6レップ（高重量、張力目的なら6〜8）
- RIR 2（限界まで引かない。フォームが崩れるレップは引かない）
- 規定レップをフォーム維持でできたら2.5〜5kg

**8. プログラムの位置（約1分）**
- 背中または脚セッションの1種目目。疲れた状態でやらない
- 週1回。回復に時間がかかる

**9. 代替案（約1分）**
- 腰が先に疲れる → ルーマニアンデッドリフト（床まで下ろさない）、ヒップスラスト＋チェストサポートロウに分ける
- 床から引けない（骨格・柔軟性）→ ブロックプル、トラップバー
- 握力で終わる → ストラップ

**10. Felipe なら（約1分）**
- 背中の日の1種目目、週1回、2〜3セット。重さを追わない
- 一番重視するのは「引く前」。スラックを抜いた時点で負荷がどこにあるか。そこで腰なら、その日はやらない
- スパイス案：床から膝までを3秒で引く「スローデッド」。張力の場所がはっきり分かる

**宿題（15秒）**
「次の背中トレで、スラックを抜いて1秒止めてから引く3レップを横から撮って、フォーム記録へ。」

## 第9弾：プッシュダウン（ケーブル）

**0. 結論（15秒）**
「プッシュダウンで肩と前腕が疲れる人は、肘が動いています。肘を止めて、三頭だけで押します。」

**1. この種目（約1分）**
- メインターゲット：上腕三頭筋（外側頭・内側頭。アタッチメントと肩の角度で長頭の関与が変わる）
- どんな動作か：肘関節の伸展のみ。肩と肘の位置を固定した単関節種目
- 王道との違い：体重を乗せて押し下げない。肘の位置を固定し、伸ばし切った位置で三頭筋を収縮させる。ケーブルの作用線に対して、前腕が垂直に近い位置で最も負荷がかかる
- 選ぶ理由：ケーブルは全可動域で張力が残り、関節への負担が少ない。プレス系で疲れた後でも三頭筋だけを追える

**2. 完成形（約30秒）**
- 3〜5レップ、側面
- 「今日は、肘を止めて、三頭筋だけで伸ばし切るプッシュダウンを作ります。」

**3. セットアップ（約2分）**
- プーリー高：頭より上。ケーブルが肘の位置で斜め上から来る高さ
- 立ち位置：マシンから半歩離れ、ケーブルが身体に沿って垂直に近く落ちる位置
- 上体：わずかに前傾（5〜10度）。腹圧で固定。前傾で体重を使わない
- 肘：体側、やや前（身体の真横より数cm前）。ここから動かさない
- グリップ：ロープ＝外側頭と収縮の自由度、バー＝重量を扱いやすい。手首は真っ直ぐ
- 肩甲骨：軽く下制。肩をすくめない

**4. 動作の徹底分解（約4分）**
- START：肘が90度より少し曲がった位置。三頭筋にすでに張力がある
- CONCENTRIC：肘を支点に、前腕だけを下ろす。手ではなく「肘の後ろで押す」
- FINISH：肘が伸び切り、三頭筋が最大収縮。ロープなら手を少し外に開いて収縮を強める。肩を前に出して押し込まない
- ECCENTRIC：肘の位置を保ったまま、前腕を戻す。重りに引かれて肘が前に出ないように
- TURNAROUND：前腕が水平より少し上（肘が100度程度）で切り返す。それ以上戻すと肩と前腕が仕事をする
- 力学：ケーブルの作用線と前腕が垂直のとき、肘のモーメントアームが最大。伸ばし切った位置では作用線と前腕が平行に近づきモーメントアームが短くなる。だから収縮位置で「止める・絞る」が必要

**5. よくある間違い・代償動作（約2分）**
- ①肘が前後に動く → 原因：重すぎる → 代償：三角筋前部・広背筋 → 修正：重量を落とし、肘を壁に当てるイメージ
- ②上体で押し下げる → 原因：体重を使う → 代償：腹筋・体幹の反動 → 修正：前傾角度を固定
- ③手首が曲がる → 原因：握り込み → 代償：前腕 → 修正：手首を真っ直ぐ、掌の付け根で押す

**6. 重量を上げた時に見るポイント（約1.5分）**
- 肘の位置（最初に崩れる）
- 伸ばし切れているか（可動域が縮む）
- 上体が動いていないか

**7. レップ・強度（約1分）**
- 10〜15レップ
- RIR 0
- 15レップを肘固定でできたら1段階

**8. プログラムの位置（約1分）**
- 腕セッションの1種目目（三頭を先に温める）、またはプレスの後の終盤
- 週1〜2回

**9. 代替案（約1分）**
- 肘が痛い → ロープで手を開く、または可動域を浅く
- ケーブルがない → ダンベルキックバック（ただし上部で負荷が抜ける）、マシンディップス
- 長頭を狙いたい → オーバーヘッドエクステンション（肩を屈曲させて長頭をストレッチ）

**10. Felipe なら（約1分）**
- 腕の日の1種目目、3セット。収縮で1秒止める
- 一番重視するのは「エキセントリックで肘が前に出ないこと」。重りに負けて肘が動く瞬間が、三頭筋から負荷が消える瞬間
- スパイス案：最後のセットは片手ずつ。肘の固定が自分で分かる

**宿題（15秒）**
「次の腕トレで、肘を止めたまま伸ばし切る1セットを横から撮って、フォーム記録へ。」

## 第10弾：バーベルカール

**0. 結論（15秒）**
「カールで肩と腰が疲れる人は、二頭筋ではなく身体で上げています。肘の位置を決めて、二頭だけで上げます。」

**1. この種目（約1分）**
- メインターゲット：上腕二頭筋（長頭・短頭）、上腕筋
- どんな動作か：肘関節の屈曲。肩を固定した単関節種目。前腕の回外で二頭筋の収縮が強まる
- 王道との違い：反動を使って重さを上げない。肘を身体の少し前で固定し、ストレッチ位置からの最初の数cmを二頭筋で始める
- 選ぶ理由：両手で最も高い負荷をかけられる。ストレッチ位置で負荷が残るので、二頭筋の長さ・張力の関係を学ぶ基本種目

**2. 完成形（約30秒）**
- 3〜5レップ、側面
- 「今日は、肘を固定して、二頭筋だけで上げ切るカールを作ります。」

**3. セットアップ（約2分）**
- 足幅：腰幅。膝を軽く緩める。腹圧で体幹を固定
- グリップ：肩幅（EZバーなら手首に優しい角度）。手首は真っ直ぐ、または軽く曲げる。反らせない
- 肘：体側のやや前。動作中この位置を変えない
- 肩：肩甲骨を軽く下制。肩を前に出さない
- スタート：肘を伸ばし切らず、わずかに曲げて二頭筋に張力を入れた位置

**4. 動作の徹底分解（約4分）**
- START：肘わずかに曲げ、張力あり
- CONCENTRIC：肘を支点に前腕を上げる。最初の数cmが最も重要（反動なしで二頭筋が始める）。手首を巻き込まない
- FINISH：前腕が垂直になる手前。肘を前に出して「上まで」上げると、負荷は三角筋前部に移る
- ECCENTRIC：肘の位置を保ったまま、2〜3秒で下ろす。ここで二頭筋に最も負荷がかかる
- TURNAROUND：伸び切る手前で切り返す。肘を伸ばし切って休まない
- 力学：前腕が水平のとき、肘のモーメントアームが最大。それより上は負荷が減る。だから「上まで上げる」より「水平付近で止めて絞る」方が張力が高い。反動で水平を素早く通過すると、一番重要な位置を飛ばしている

**5. よくある間違い・代償動作（約2分）**
- ①上体を反らせて反動 → 原因：重すぎる → 代償：腰・三角筋前部 → 修正：重量を落とし、壁に背中をつけて練習
- ②肘が前に出る → 原因：上まで上げようとする → 代償：三角筋前部 → 修正：前腕が垂直になる手前で止める
- ③手首が巻き込む → 原因：前腕で引く → 代償：前腕屈筋群 → 修正：手首を真っ直ぐ固定、EZバー

**6. 重量を上げた時に見るポイント（約1.5分）**
- 上体の揺れ（最初に出る）
- 肘が前に出る
- エキセントリックが速くなる（落としている）

**7. レップ・強度（約1分）**
- 8〜12レップ
- RIR 0〜1
- 12レップを反動なしでできたら1.25〜2.5kg

**8. プログラムの位置（約1分）**
- 腕セッションの最初の二頭種目。または背中の日の最後
- 週1〜2回

**9. 代替案（約1分）**
- 手首・肘が痛い → EZバー、ダンベル（回外を使える）
- 反動が止まらない → プリーチャーカール（肘を固定してくれる）
- 肩の前が疲れる → インクラインダンベルカール（肩を後ろに置き、二頭筋をストレッチ）

**10. Felipe なら（約1分）**
- 腕の日の1種目目、3セット。エキセントリック3秒
- 一番重視するのは「最初の数cmを二頭筋で始めること」。反動を使った瞬間に、その日のセットは腕のセットではなくなる
- スパイス案：最後のセットは前腕が水平の位置で2秒止める「ミッドレンジホールド」

**宿題（15秒）**
「次の腕トレで、壁に背中をつけてやる1セットを横から撮って、フォーム記録へ。」
